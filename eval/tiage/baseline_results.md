# TIAGE 基线结果

阶段 1 用词袋出第一个基线，阶段 2 接 BGE-M3 真 encoder 重跑，验证切割质量上限。

## 数据

- 来源：TIAGE Anno test（100 对话，1564 turn，315 topic-shift 标注）
- 转换：turn 级 0/1 标签 → 统一 eval 格式 boundaries（`eval/convert_tiage.py`）

## 结果

我们的切割算法 = 承接分数（相邻 turn 余弦相似度）+ DP 切割（切点代价 = score - threshold）+ overlap。

| encoder | threshold | tol=0 F1 | tol=1 F1 | tol=0 P/R | tol=1 P/R |
|---|---|---|---|---|---|
| WordBag（词袋，零模型） | 0.35 | 0.329 | 0.634 | 0.259 / 0.451 | 0.499 / 0.870 |
| BGE-M3（默认阈值） | 0.50 | 0.365 | 0.560 | 0.404 / 0.333 | — |
| **BGE-M3（最优阈值）** | **0.65** | **0.397** | **0.637** | **0.309 / 0.556** | — |

## 对照 TIAGE baseline（论文报告，tol=0）

| 方法 | F1 |
|---|---|
| BERT-Wiki727k（主题分割预训练 BERT） | 0.038 |
| GenEnc（embedding 余弦 + 阈值 0.25） | 0.250 |
| Ours（WordBag + DP） | 0.329 |
| **Ours（BGE-M3 + DP，th=0.65）** | **0.397** |
| RetroTS-T5（T5 微调，有监督） | 0.682 |
| Human | 0.644 |

## 分析

1. **BGE-M3 零样本显著超过词袋**：F1 0.329 → 0.397（+20.7%）。precision 0.259 → 0.309、recall 0.451 → 0.556，双升，说明真实语义 embedding 确实提升了承接分数区分度。

2. **但未达有监督 RetroTS-T5（0.682）**：BGE-M3 零样本 + DP 只到 0.397，与 RetroTS-T5 的 0.682 仍有明显差距（TIAGE 人工标注一致性仅 0.479，说明该任务本身就难）。这也印证了阶段 5「对比学习训练专用承接模型」的必要性——零样本通用 embedding 有上限。

3. **BGE-M3 的阈值分布比词袋偏高**：BGE-M3 相邻 turn 余弦相似度整体偏高（0.5~0.7），最优 threshold=0.65；词袋最优在 0.35。默认 threshold=0.5 对 BGE-M3 偏低（F1=0.365），需按 encoder 调阈值。

## 训练模型结果（阶段 5）

| 模型 | threshold | tol=0 F1 | tol=1 F1 | tol=0 P/R |
|---|---|---|---|---|
| bge-m3 零样本 | 0.65 | 0.397 | 0.637 | 0.309 / 0.556 |
| OASST1 微调（MNRL） | — | **0.464** | — | — |
| 任务型微调（MultiWOZ + DialSeg711）| 0.45 | 0.428 | 0.645 | 0.381 / 0.489 |
| **平衡模型（OASST1+任务型，seq=2048）** | 0.60 | 0.458 | 0.641 | 0.366 / 0.613 |

- OASST1 闲聊微调最优（0.464）；平衡模型（0.458）接近 OASST1、高于零样本与任务型。
- 完整对比与训练配方见 `docs/milestones.md`。

## 复现

```bash
# 转换 + 评估
uv run python -m eval.convert_tiage
uv run python -m eval.run tiage bge_m3        # 默认阈值
uv run python -m eval.sweep tiage bge_m3      # 阈值扫描找最优
```
